A practical explanation of the app’s data flow and this website. For the implementation details, the source is open to inspect.

Where your files live

TeleDrive is a native Android client for a library stored in private Telegram channels you choose. Normal uploads use TDLib, Telegram’s client library, to send originals and file metadata to Telegram. The developer does not operate a storage server for this path.

Telegram is the storage provider. Its cloud chats are not end-to-end encrypted by default, and its service limits and account controls apply. Removing a channel or its file messages can remove stored content. Keep an independent copy of important files.

What stays on your phone

The app keeps an index, preferences and cached media so it can display and play your library. Authentication credentials and encryption-related local records use the app’s protected storage. Some media and transfers may remain on your phone until you remove them or clear the relevant cache.

Signing out and clearing data have different effects from deleting content in Telegram. Read the app’s confirmation screens before removing a channel, file or encryption key.

Protection you can choose

  • Hidden lock: uses Android’s fingerprint or screen-lock verification. It does not read or store the phone’s PIN, pattern or password. It controls access in TeleDrive and is separate from file encryption.
  • Optional encryption: file and thumbnail encryption can be enabled in the app. Save the matching recovery material somewhere safe, outside the phone. Signing in again does not recreate a lost encryption key.
  • App lock and screenshot blocking: available through the security settings. Device behavior and Android support can vary.

Permissions and connections

File selection, camera capture, document scanning, notifications and folder backup use the relevant Android permissions and services. Document scanning requires supported Google Play services. Google Photos import uses local Google Takeout exports; it is not a Google sign-in on this site.

Release checks contact GitHub. Optional sharing or external services, if configured in the app, use the destinations you select. These are separate from normal private-channel uploads.

This website

This is a static GitHub Pages download site. It has no account form, file-upload form, advertising scripts, analytics SDK or third-party font requests. It does not ask for a Telegram phone number, login code, password or API credentials.

Your theme choice is saved in this browser’s local storage when available. Download information is loaded from a small file on this site. Clicking an APK link takes you to GitHub Releases. GitHub handles hosting and release downloads according to its own privacy practices.
