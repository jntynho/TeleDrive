# متابعة إجراءات Telegram وGallery وشاشة البداية

هذه المتابعة تأتي بعد الإصلاحات العامة في البناء55، وتضيف الطلبات الأربعة التالية:

1. **Telegram:** تستخدم إجراءات الملف مراجع أجزائه مع قناة كل جزء بدل افتراض قناة الملف الرئيسية. يُجرّب المرجع البديل عند غياب الرسالة، وتُصحّح معرّفات server القديمة إلى صيغة TDLib. عند رفض تصدير رابط لقناة خاصة يبقى الرابط المباشر للرسالة المؤكدة متاحًا. الإرسال يعيد استخدام مرجع الملف البعيد إذا فُقدت رسالة المصدر، ولا يعيد إرسال طلب لم يُؤكد حتى لا يتكرر الملف. الصلاحيات والمحتوى المحمي وحدود Telegram لا تُتجاوز.

   الملف المحلي أو المشفر أو المقسم له مسار **Open Telegram with original**: إعداد الأصل وفك التشفير محليًا عند الحاجة، ثم فتح عميل Telegram المثبت لاختيار المحادثة، مع منح قراءة URI. لا تُرسل قطعة منفردة أو بيانات مشفرة على أنها الأصل. هذا المسار قد يحتاج تنزيلًا ثم رفعًا داخل Telegram؛ النسخ المباشر للملف العادي يبقى دون إعادة رفع. الملف الذي لم يُرفع بعد يعرض إجراء **Upload and show in Telegram** بدل زر معطل غامض. فشل/إلغاء التحويل يظهر دون انتظار صامت30 دقيقة.

   فتح Intent لا يثبت أن حساب Telegram الخارجي يملك حق الوصول: يجب استخدام حساب مالك القناة. الرسالة المحذوفة فعلًا دون مرجع بديل لا يمكن فتحها، وغياب Telegram يُعرض بوضوح. تظهر هذه الحالات للمستخدم بدل الادعاء بنجاحها.

2. **إصبعان في Gallery:** جلسة إيماءة ثابتة لا تُعاد بسبب تغير callback أثناء التركيب. تجمع مقدار التكبير وتغيّر الكثافة عند رفع الأصابع فقط، مع معاينة تحجيم محدودة وحركة استقرار220ms. حفظ الأعمدة مرة واحدة، وحفظ الملف تحت مركز الإيماءة كمرساة للتمرير. الحد الأقصى للأعمدة لا يحوّل Gallery تلقائيًا إلى List. إلغاء الإيماءة لا يحفظ تغييرًا، والتحديد الطويل لا يبدأ أثناء لمس بإصبعين.

3. **التسخين:** شاشة أنظف بأيقونة التطبيق، وخلفية من لون الثيم ولمسة لونية خفيفة، وعنوان ومؤشر نقاط صغير. وضع مضغوط للشاشات القصيرة، ودلالات وصول موحدة. لا نسبة تقدم وهمية ولا تأخير ثابت جديد؛ الإغلاق مرتبط بالجاهزية المحلية الفعلية السابقة.

4. **الأيقونة:** استعادة موارد Aero Fold المتجهة نفسها من الإصدار54، مع foreground/background منفصلين وmonochrome للنظام، واستعادة ملفات SVG والمولّد والمعاينة وREADME. توقيع التطبيق وهويته لا يتغيران.

الاختبارات تضيف مراجع أجزاء من قناة مختلفة، وغياب رسالة مع مرجع بديل، وعدم تكرار إرسال غير مؤكد، وروابط القنوات الخاصة والمعرّفات القديمة، وURI المشاركة وأذونات القراءة، واستمرار إيماءة الإصبعين عبر إعادة التركيب وحفظ القرار عند رفع الأصابع. حساب Telegram حقيقي وقياسات GPU على هاتف لا تدخل في الاختبارات الآلية.

التحقق المحلي:314 اختبار app و66 اختبار shared دون فشل، وrelease lint دون أخطاء مانعة، وترجمة اختبارات Android. ملفات الأيقونة المستعادة تطابق المولّد السابق عبر `python3 scripts/generate_launcher.py --check`. نشر APK يظل مشروطًا باختبارات الجهاز وفحوص توقيع وحجم ومواءمة نسختَي ARM في Actions.
